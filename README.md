# 🥚 铁蛋运维工具集

> 运维人必备的自动化工具合集

## 工具列表

### 🔍 server-health-checker.py
一键检查服务器所有关键指标（CPU、内存、磁盘、负载、Docker、系统服务）

### 💰 stablecoin-arbitrage-monitor.py
稳定币价差监控工具 - 监控Binance、OKX、Bybit等交易所的USDT/USDC价差，自动告警

### 📊 stablecoin-arbitrage-dashboard.html
价差监控Web看板 - 实时显示各交易所价差，趋势图表

## 使用方法
```bash
git clone https://github.com/miraclestar-w/ops-tools.git
cd ops-tools
python server-health-checker.py
python stablecoin-arbitrage-monitor.py
```
