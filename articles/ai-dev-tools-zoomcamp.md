## 为什么推荐这个课程

最近在 GitHub 上刷到一个叫 **AI Dev Tools Zoomcamp** 的开源课程，点进去看了看，确实有点东西。

这个课程出自 DataTalksClub——就是之前出过 Data Engineering Zoomcamp 和 MLOps Zoomcamp 的那个社区。这次他们的方向很明确：**教你怎么用 AI 工具写代码，写得更快、写得更好**。

课程完全免费，2025年11月开启了第一期，所有资料都开源在 GitHub 上，视频也上传到了 YouTube。对于预算有限但想学 AI 开发工具的运维同学来说，这可能是目前最友好的入门路径了。

## 课程到底讲什么

先说结论：这个课程**不是教你怎么训练模型**，而是教你怎么**把 AI 工具用到日常开发流程里**。这个定位特别务实，也是我觉得它适合运维转型的原因——你不需要去啃论文，不需要会 PyTorch，只需要会写代码（或者愿意开始写）。

课程一共分6个模块：

**模块一：AI 工具全景概览**

这一节是个大扫盲，把当前主流的 AI 辅助开发工具过了一遍。包括聊天类工具（ChatGPT、Claude、DeepSeek）、编码助手/IDE（Cursor、GitHub Copilot、Claude Code）、项目快速生成器（Bolt、Lovable），还有各种 Agent 框架。说白了就是让你先知道有什么工具可以用，怎么分类，各有什么长处。以前搞运维的时候，我们也是先了解市面上有哪些监控工具、配置管理工具，然后才挑着用的。学 AI 工具也是一样的思路。

**模块二：端到端项目实战**

拿一个贪吃蛇游戏做案例，从零开始：用 AI 编码助手搭建 React/TypeScript 前端，通过 OpenAPI 规范定义 API，再用 FastAPI 生成后端，加上 CI/CD 流水线，最后部署上线。这一节的价值在于它不是孤立地教某个工具，而是演示了一个完整的开发流程。对运维同学来说，CI/CD 和部署那些环节你已经很熟了，缺的可能就是前面怎么用 AI 快速搭建业务逻辑这块。

**模块三：Model Context Protocol（MCP）**

这个模块比较前沿。MCP 是 Anthropic 提出的一个开放协议，让 AI 助手可以调用外部工具和数据源——比如 GitHub、文件系统、数据库、HTTP 接口等。通俗理解就是：给 AI 装上手脚，让它不只是聊天，还能真正操作你的系统。课程会教你怎么配置 MCP Server，怎么做代码仓库的自动分类、PR 摘要生成、数据查询等实际操作。

**模块四：自己造一个 AI 编码 Agent**

这一节动手含量很高。你会从零构建一个能自动搭建和扩展项目的 AI Agent，底层用 Django 模板做基础项目。还会接触到多个 Agent 编排框架，最终让你的 Agent 能自动创建和修改一个完整的 Django 应用。搞过自动化的运维同学应该对这个很有感觉——本质上就是在做一种更智能的自动化编排。

**模块五：AI 驱动的测试、CI/CD 与 DevOps**

这一节跟运维最相关，也是我最推荐你先看的。内容包括：

- AI 辅助的 PR 审查和变更风险评估
- 自动生成测试用例、覆盖率检查、LLM 评估集成到 CI 流程
- 自动生成发布说明、变更日志、部署手册
- 事故复盘和 on-call 智能助手

这些场景你细想一下，都是运维日常在干的活。现在 AI 能帮你把这些重复性工作自动化掉，效率提升是肉眼可见的。

**模块六：低代码/无代码 AI 自动化**

用 n8n 这个开源自动化平台做一些实际操作，比如自动生成 LinkedIn 帖子、根据岗位描述定制简历。这个模块相对轻松，更多是让你体验 AI 自动化的可能性。

## 对运维同学的建议

如果你是运维背景，想往 AI 方向靠，我建议这么学：

1. **先看模块五**（CI/CD 与 DevOps），因为跟你的日常工作最接近，容易上手也容易产出成果
2. **再看模块一**，建立对 AI 工具的整体认知
3. **然后按顺序走模块二到四**，跟着做项目，动手比看书管用一百倍
4. 模块六可以当调味品，放松的时候看看

不需要一步到位，每天花一两个小时跟着做，比囤课强太多。
